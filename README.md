# Student Management and Grading System

A menu-driven Student Management and Grading System developed using Python.

### Features
- Add new student records
- View all student records
- Search students using roll number
- Edit student marks
- Delete student records
- Calculate total marks, percentage and grades automatically
- Validate marks and user inputs

### Technologies Used
- Python
- Dictionaries
- Lists
- Functions
- Conditional Statements
- Loops

### Data Storage
Student records are stored in an in-memory Python dictionary. Data is not permanently stored and is lost when the program terminates.
